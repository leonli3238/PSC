GT-PSC 贴近论文的收敛实施方案（2026-09-28）

本方案按用户最新目标重新确定范围：使项目 GT-PSC 的算法设定与实验结果尽可能接近论文。此前提出的作者询问和新估计器路线均不作为本轮工作的依赖或实施内容。当前阶段交付方案，不替换生产算法或默认结果。

推荐采用“固定论文任务和指标 -> 联合使用 Table 2/3 约束 -> 比较少量有依据的实现配置 -> 选定一致配置 -> 独立随机流确认”的流程。先解决 k-star，再检查 EE triangle 的局部差距。不能只把六图均值作为接近论文的判据。

**1. 锁定论文明确的设定**

- degree/k-star/triangle 的任务定义、原图与任务真值、epsilon=2、RE=abs(estimate-truth)/max(truth,.001n)。
- k-star 使用节点局部组合数；保留 PSC 的估计最大度、投影、节点报告、聚合结构，不引入另一种估计器。
- 不同方法按同一代码中的明确机制配置执行；GT 与 agent 后续共用这些配置，不能只改 GT 输出。
- 论文点值、已有历史结果与新实验结果分别保存。将全部 12 个 k-star GT-PSC 单元格作为 Table 2 主目标，Table 3 的 4 个 k-star GT-PSC-B 单元格作为附加约束；重复出现的 GT-PSC 单元格不重复计权。

**2. 首轮明确候选，不做任意参数堆叠**

| 配置 | 投影 D | 报告 GS | 地位 |
|---|---|---|---|
| legacy | ceil(M) | C(D,k-1) | 当前基线 |
| floor_bound | floor(M) | C(D,k-1) | 引用论文的整数阈值解释 |
| continuous_bound | floor(M) | M 或 M(M-1)/2 | 引用源码的精确行为 |
| floor_tight | floor(M) | C(D-1,k-1) | 固定 D 下理想裁剪计数的数学紧界；论文未明确采用 |

主比较固定 epsilon2=.4、epsilon3=1.6；不能因为某项更接近就逐数据集改变预算。针对其他预算解释的诊断仅作为单独第二轮，不扩大成任意网格搜索。连续 M 限制到 [0,n-1]；离散候选也应明确同样的物理范围。D<k 时局部计数恒为零，紧 GS 相应为零，由确定性返回处理，不把非法组合数或负 scale 传入机制。

真实邻居投影与不投影、最终负值截断与不截断可在独立审计路径比较，因为 PSC 未公布完整 k-star 库；其中不满足所选 GS 条件的组合只作定位，不能选入正式 epsilon=2 基线。按节点提前截断、重复公开发布求平均等操作没有当前原文依据，不作为默认候选。

目前已有证据支持将 floor_tight 作为优先验证候选，但尚未选为最终默认：

| 指标 | legacy | floor_tight | 论文 |
|---|---:|---:|---:|
| 2-star 六图平均 RE | .11451 | .10315 | .0647 |
| 3-star 六图平均 RE | .45303 | .37596 | .3649 |
| 3-star 逐格相对差距均值 | 22.7% | 11.8% | 0 |
| 3-star 最差单格相对差距 | 51.2% | 22.7% | 0 |

上述为既有 50000 次配对实验。3-star 接近程度确有改善，但 CU 从 .8821 到 .6999，论文 .8035；不能只看到六图均值接近就宣布完成。2-star 的剩余差距仍大，需要下一步表格约束定位。

**3. 2-star 改用 Table 2/3 联合定位**

按以下依赖顺序推进：

    GT-Naive 的 RR/任务计数一致性
        -> GT-PSC-B 的局部计数、基础 GS、报告噪声、聚合
        -> GT-PSC 新增的最大度、预算分配、投影和优化 GS

这是新增的关键约束。GT-PSC-B 不执行最大度估计和投影；若它已经偏离，就不能把 GT-PSC 的所有差距归因于 noisy max。PSC-B 也改变可用报告预算，比较时必须记录这一点。

3.1 基本数据和计数核对：直接重算每图 degree 向量、T2、T3，并利用 RR 期望恒等式与论文 GT-Naive 做一致性检查。设 p=1/(1+exp(epsilon))、q=1-2p、N=n-1，则

    E[T2(RR(G))] = q^2*T2(G) + pq(N-1)*2m + np^2*C(N,2)
    E[T3(RR(G))] = q^3*T3(G) + pq^2(N-2)*T2(G)
                  + p^2*q*C(N-1,2)*2m + np^3*C(N,3)

将论文 GT-Naive 的大幅正偏近似为有符号 RE 后，反推的六图 T2/T3 与当前真值相对差异均小于 .5%。这是进一步降低基本任务定义或真值相差很大的可能性，不能据此证明边集合与作者完全相同，也不能忽略绝对值和有限样本近似。

3.2 在无优化 PSC-B 上隔离报告尺度：固定准确原始计数，使用已验证的 Laplace 和分布闭式计算期望 RE，并与 Table 3 对照。当前结果为：

| 数据集/任务 | 当前 PSC-B 理论 RE | 论文 PSC-B | 把论文点值当期望所反推的 scale/当前 scale |
|---|---:|---:|---:|
| CU/2-star | .44858 | .4487 | 1.0003 |
| Do/2-star | .29732 | .2580 | .8667 |
| CU/3-star | 5.17179 | 4.6370 | .8864 |
| Do/3-star | 2.71710 | 2.4373 | .8780 |

比例并不统一，不能据此乘一个全局校准常数，更不能按数据集写系数。反推仅定位所需变化量，不是作者实际尺度测量。下一步在 PSC-B 的可解释差异上比较 n、n-1、紧上界和最终截断，并模拟固定 1000 次组均值的波动，检验论文点值与候选分布的相容性。表中的不同大小差异也可能包含不同随机流/重复数的波动，不能直接判定为尺度 bug。

3.3 PSC-B 核对完成后，再将相同报告和聚合语义带入 GT-PSC，对比四种 D/GS 配置。允许不同任务因其数学定义使用不同 GS；不允许同一任务按数据集改机制来追表格。

若当前共同尺度独立报告结构的候选全部不能进一步贴近 2-star，应结束这一族内无效的取整/预算重跑，保留最佳有依据配置和剩余差距。已有理想阈值研究显示 ML/EE/PM 的论文 2-star 点值低于该机制族最优期望；因此不能预先承诺全部格子误差小于 5%。

**4. 接近论文的选择指标**

候选评分使用各单元格的相对比例，而不是平均 RE 大小：

    J(profile) = mean_cell |log(RE_profile / RE_paper)|

同时报告每格相对差距和最大差距。对于 Table 2/3，按唯一单元格计权；Table 2 的 k-star 主分数与 Table 3 的 PSC-B 分数分别展示，避免一个抵消另一个。数学/机制依据不成立的候选不参加默认选择。

显著差于当前配置的单格必须解释；不能用许多小格子的改善掩盖大幅退步。对有原文歧义的候选，可以按数据支持选择最贴近的公开描述实现，但报告中要注明选择用到了论文表值，这不等于独立复现作者代码。

跨随机流确认用来排除挑种子；它不能消除按公开表格选择配置本身的偏向。若使用留一数据集的配置选择检查，它只是稳定性分析，因为全部论文表值已经被看过，不称其为未见测试集。

**5. 运行次数和结果输出**

- 首轮对新组合每格 5000 次。既有配置直接复用已校验结果，不无理由重跑。
- 只对排名接近或未解释的关键候选补到每格 20000 次，报告整次运行的 RE 标准误。
- 配置冻结后，用预先固定的新随机流生成一份每格 1000 次的论文格式结果，再同时保存稳定均值参考。
- 用独立 1000 次组均值分布检查小样本不确定性，不通过重复运行选择最接近论文的一组。
- Table 2、Table 3 之外，用 Exp2 的 epsilon 趋势做辅助一致性检查；图中无法精确读取的数值注明读图误差，不当作四位小数真值。

**6. 工程实现范围**

| 文件 | 拟修改 |
|---|---|
| 新增 `psc/mechanism.py` | 定义 D 取整、M/D 分离、GS 模式、基础边界、报告及最终截断的配置 |
| `psc/dp.py` | 可记录连续 M、离散 D、度报告、标准噪声；trace 不额外消费随机数 |
| `psc/library.py` | 显式区分论文上界、引用源码连续上界和紧界 |
| `psc/ground_truth.py` | 接收机制配置，统一计数、报告、聚合，保存截断前后结果 |
| `psc/agents/privacy_controller.py` | 后续采用同一个机制实现，避免与 GT 取整逻辑重复且漂移 |
| `psc/experiments.py` | 增加逐格论文差距、标准误、Table 2/3 联合对照 |
| `scripts/run_ground_truth.py` | 增加机制参数，保留默认 legacy 直至候选冻结 |
| 新增 `scripts/align_gt_psc.py` | 执行固定候选矩阵、分阶段比较和最终确认 |

以上新文件与参数均为方案，不是当前可用接口。先完成独立局部差分、预算总和、零尺度、固定噪声回算和 GT/agent 参数一致性检查，再决定默认配置。后续若确认候选更符合目标，将其配置设为 GT-PSC 默认，历史机制保留为 legacy，不把论文表值进入估计器运行时。

**7. 最终交付与验收**

交付一个选定机制配置、一份 Table 2/3 逐格对照、一份旧版到新版的参数和效果差异，以及未消除差距清单。核心验收为：同一配置跨数据集执行；总体及最大逐格差距改善；新随机流稳定；degree/GT-Naive 等已接近项不因共享模块变化退步。若选定配置仅改善 3-star，明确报告 2-star 剩余差距，不能把总体平均的改善称为全部对齐。

优先实施顺序：机制配置与 trace -> PSC-B/Naive 表格约束 -> floor_tight 等候选验证 -> 选定配置与独立确认 -> GT/agent 共用参数。整个流程不依赖联系作者，也不引入新估计器。
